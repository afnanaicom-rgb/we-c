# We-C - تطبيق اجتماعي احترافي 🚀

تطبيق اجتماعي حديث وسريع مع غرف دردشة تفاعلية وميزات إدارية متقدمة.

## الميزات الرئيسية ✨

### 1. **الصفحة الرئيسية (afnan_ai_white.html)**
- عرض الغرف العامة والخاصة
- شريط جانبي بمعلومات المستخدم
- عرض الملف الشخصي مع الإطارات والشارات
- نظام المحفظة والشحن
- متجر شامل للعناصر
- حقيبة المستخدم (Bag)

### 2. **غرف الدردشة (room.html)**
- دردشة فورية مع تحديثات حية
- عرض الرسائل مع الإطارات والشارات
- نظام الليفل (Magic Level & Wealth Level)
- عرض الـ ID المخصص (customId) لكل مستخدم
- إرسال الهدايا والألعاب
- ترتيب الغرفة

### 3. **ميزات الإدارة 🔐**
- **تغيير الـ ID المخصص**: للأدمن فقط عند فتح ملف المستخدم
- **شحن الرصيد**: إضافة رصيد لأي مستخدم مباشرة
- **حظر المستخدمين**: مع تسجيل السبب
- **إدارة المشرفين**: إضافة/حذف مشرفين الغرفة
- **تغيير إعدادات الغرفة**: الاسم والخلفية

### 4. **التأثيرات البصرية 🎨**
- تأثيرات 3D متقدمة على الإطارات
- تأثيرات الإضاءة والتوهج (Neon Glow)
- تأثيرات الحركة السلسة والانزلاق
- تأثيرات الموجة والانعكاس
- تأثيرات الظل الديناميكي
- خلفيات متدرجة ملونة
- تأثيرات الزجاج المتقدمة

## البنية التقنية 🏗️

### الملفات الرئيسية
```
we-c/
├── index.html              # الصفحة الرئيسية (تحويل)
├── afnan_ai_white.html     # الصفحة الرئيسية الفعلية
├── login.html              # صفحة تسجيل الدخول

├── css/
│   ├── home.css            # تنسيقات الصفحة الرئيسية
│   └── advanced-effects.css # التأثيرات المتقدمة
├── js/
│   ├── firebase-config.js  # إعدادات Firebase
│   └── home.js             # منطق الصفحة الرئيسية
```

### التقنيات المستخدمة
- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Backend**: Firebase (Firestore + Realtime Database)
- **المكتبات**: 
  - SVGA Player Web (للرسومات المتحركة)
  - Lucide Icons (للأيقونات)
  - Tailwind CSS (للتنسيقات)

## كيفية الاستخدام 📖

### التسجيل والدخول
1. انقر على زر "تسجيل الدخول"
2. استخدم بيانات اعتمادك
3. سيتم إنشاء حساب جديد تلقائياً عند أول دخول

### الدخول إلى الغرف
1. من الصفحة الرئيسية، اختر غرفة من القائمة
2. ستُفتح صفحة الغرفة مع الدردشة الحية
3. استخدم الأيقونات السفلية للهدايا والألعاب

### الميزات الإدارية
1. **تغيير الـ ID**: افتح ملف المستخدم (للأدمن فقط)
2. **شحن الرصيد**: أدخل المبلغ واضغط "شحن"
3. **حظر المستخدم**: أدخل السبب واضغط "حظر"
4. **إدارة الغرفة**: اضغط على أيقونة الإعدادات

## معايير الأمان 🔒

- **المصادقة**: عبر Firebase Authentication
- **الصلاحيات**: نظام admin/user محدد
- **تشفير البيانات**: جميع البيانات مشفرة في Firebase
- **التحقق من الجلسة**: التحقق من صلاحيات المستخدم قبل أي عملية

```javascript
  apiKey: "YOUR_API_KEY",
  authDomain: "YOUR_AUTH_DOMAIN",
  projectId: "YOUR_PROJECT_ID",
  storageBucket: "YOUR_STORAGE_BUCKET",
  messagingSenderId: "YOUR_MESSAGING_SENDER_ID",
  appId: "YOUR_APP_ID",
  databaseURL: "YOUR_DATABASE_URL"
```

تعديل `ADMIN_UID` في `room.html` بمعرف الأدمن الفعلي.
